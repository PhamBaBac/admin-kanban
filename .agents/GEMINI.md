# Kanban App — Agent Rules

## Project Context

This is a full-stack Kanban application:
- **Frontend (admin-kanban)**: React + Vite
- **Frontend (kanban-shopping-app)**: React + Vite  
- **Backend (kanban_service)**: Spring Boot (Java)

---

## Mandatory Skill Usage

**ALWAYS activate and follow these skills whenever working on UI, components, pages, styling, or design:**

- `ui-ux-pro-max` — Must be used for ALL UI/UX work: building pages, components, styling, color, typography, layout, animations, charts, and design systems. Do NOT write any frontend code without first reading this skill.
- `design-system` — Must be used when creating or modifying the design system, tokens, or theme files.
- `ui-styling` — Must be used when writing CSS, styled-components, or any styling logic.
- `design` — Must be used for design decisions, mockups, or visual direction.

> Even if the request seems simple (e.g., "add a button"), you MUST still consult the relevant skill above before implementing.

---

## General Coding Rules

- Use Vietnamese in all comments and commit messages.
- Follow existing code style in each sub-project.
- Always prefer modifying existing components over creating new ones.
- Never hardcode credentials or secrets.
